# Hermes IDE 2.3.1

The strip under a session that lists the agent's replies now explains itself and never hides replies past the edge.

## Changed

- The strip is now labelled "Agent replies", with an (i) that explains it. Each chip is one reply from the agent and the lines it changed (+added −removed). Click one to see its changes or restore your files to that point.
- When there are more replies than fit, the newest ones are shown and a "+N earlier" chip opens a list of every reply, with its time, files and lines changed. You can scroll it and use it with the keyboard.
- Chips are never cut off at the edge, and the strip still works in narrow split panes.
- In a task with extra folders, the strip says that it tracks changes in the main project only.
