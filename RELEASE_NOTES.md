# Hermes IDE 2.2.0

Hermes 2.2 lets you hand files and images to an agent the moment you start a task.

## Attach files and images to a new task

- Paste a screenshot or a copied image straight into the task field of the New Session window, and it is attached instead of pasted as text.
- Drop files from your file manager onto the New Session window, or pick them with **Attach…** under the task field.
- Each attachment shows as a chip, with a small preview for images, and can be removed before you start.
- The agent receives the task together with the location of every attached file, so it can read them from its first answer. In Agent view, attached images are also sent to Claude as images.
- A file dropped on the New Session window no longer also lands in the terminal or file explorer behind it.
- Pasted images are kept for a week, then removed on their own. Files you attach from disk are never moved or changed.
